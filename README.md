# Personal-finance-tracker
Μια εφαρμογή διαχείρισης προσωπικών οικονομικών  Ο χρήστης καταχωρίζει έσοδα και έξοδα, ορίζει μηνιαίο budget και βλέπει πού πηγαίνουν τα χρήματά του. - Κατηγορίες εξόδων και μηνιαία στατιστικά. - Διαδραστικά γραφήματα και φίλτρα. - Login / registration και αποθήκευση δεδομένων. - Ειδοποίηση όταν ξεπερνά το budget.
